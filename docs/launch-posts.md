## X（中文，v0.6.0 国产套餐规则）

配图：README 同款真实下拉卡片（北京时间渲染，GLM 与 DeepSeek 显示当前档位与切换时刻）。

**主帖**

```
同时订阅 GLM、Kimi、MiniMax、DeepSeek，再加 Claude Code 和 Codex 的人，每天都在切网页看额度、算 5 小时池什么时候重置、猜现在是不是谷时。

我把这些塞进了 macOS 菜单栏：六家一屏，5h/7d 用量、重置时间、烧得偏快还是偏慢。

新版加了国产套餐才有的两条规则👇
```

**回复 1**

```
峰谷时段，按北京时间算，内置 2026 年国办放假安排：
· GLM Coding Plan：工作日 14–18 点高峰，其余积分五折
· DeepSeek API：工作日 9–12、14–18 高峰，其余半价，法定节假日全天谷时

菜单栏直接告诉你"现在谷时、五折、18:00 切换"。
```

**回复 2**

```
GLM 新版套餐按积分计量，接口返回 CREDIT_LIMIT，工具会识别并标注。
坦白说：我手里只有旧版账号，这条没用真实 V3 账号实测。7 月 30 日后新买 GLM 套餐的朋友，跑一次 coding-usage-bar status --refresh 把 GLM 那几行贴给我（不含 key），我来确认。
```

**回复 3**

```
Claude Code / Codex 只读本机文件，国产四家的 key 只存本地，直接请官方额度接口。macOS，需要 Node，会自动装 SwiftBar 做宿主。

npx coding-usage-bar install

开源：github.com/hanzhangzzz/coding-usage-bar
不做套餐推荐，不替你切模型，就是把该看的数字放在抬头能看见的地方。
```
